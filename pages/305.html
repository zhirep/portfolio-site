Edmonton Property Search

Project Summary

Edmonton Property Search was a final project for an object oriented programming course. This app is a responsive web application that allows users to search, filter, and explore property listings within Edmonton. Users can refine results by price range, property type, and location. The project was developed in IntelliJ, along with an API called ArcGIS to display the maps and plot points on it. This was a project done in around 6 weeks and was completed with another person.

Problem and Goal

Edmonton Property Search provides the solution by offering them a tool that is both easy to use and useful. Properties are marked by points on the map and color coded based on their filter customizations.

My Role

My role in this project was a main developer. I implemented the API, in this case, ARCGIS, to help with displaying the map of Edmonton, as well as to help plot the points on the map.

In addition to development, I conducted testing and verification to ensure that the data provided and displayed are valid and accurate.

Video Transcript

  • Upon loading the application, users may customize filter settings depending on the what kind of property they want to view. These settings include the type of property such as residential, commercial, garage included, and if they want to specify which ward or neighborhood.
  • Clicking the "Search Properties" button loads the results with information such as the median, mean, range, and the number of properties found.
  • Selecting the "View Details" button will display the map with the plotted locations of the properties from the filters selected.
  • Clicking on a property displays its details
  • If filters are customized, it will show properties as green points if matching the filter settings; if not, it plots them red.

Technologies Used

  • Java
  • IntelliJ
  • ArcGIS
