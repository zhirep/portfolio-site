Everstrife

Project Summary

Everstrife is a top-down action-adventure role-playing game (RPG) developed using the Unity game engine. The project was created as part of CMPT 330 with the goal of exploring real-time game development concepts, including player input systems, artificial intelligence, physics, and user interface design.

Problem and Goal

The player assumes the role of a Ranger, a versatile class designed to balance close-range and long-range combat. You must explore the world of Pandamonia to seek fame, power, and wealth.

My Role

Before development, we made documents about the game for the planned mechanics, controls, player objective, progression, and possible enemy types in the game. A lot of it, such as the controls were researched from previous games that are similar in genre, mainly the retro zelda games. As a result, the controls, the items, and the general premise of the game are pretty similar to them. The document is available below and is called Everstrife Planning Designs. At the beginning of the development process, I researched the topic of pathfinding, specifically the different types. Our findings taught me that there are six types of pathfinding algorithms, and one of the fastest is called A* Pathfinding. A* is a search algorithm that takes the formula of F = G + H, where F is the sum, G is the cost of movement in order to move from starting to end location, and H is the estimate cost of the cheapest path. For this project, we ultimately decided to use this algorithm. Details about our findings are found below in the Game Research Paper document.

My role in this project was primarily a developer. I implemented core features such as dashing, ranged, and melee attacks, among others. This also included all the SFX corresponding to a game action. I also added AI Pathfinding functionality by importing A* Pathfinding into our project and modifying some behaviors to our liking, such as the range at which the AI starts tracking the player, as by default it's set to global.

I was also responsible for minor UI functionality, including player UI bars, enemy HP, and item notifications. This also included using a software called Krita to modify some of the assets.
