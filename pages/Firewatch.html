FireWatch

Project Summary

FireWatch was our final project for the Web Development course. FireWatch is a web application that visualizes wildfire activity across Alberta by plotting them in an interactive map and display their status. Additionally, weather is also displayed.

FireWatch also provides its users with valuable information such as wildfire prevention and what to do if one were to happen. It also has optional features such as login, signup, as well as contacts functionalities.

Problem and Goal

Wildfires get common in Alberta especially around the summer season. With FireWatch, you are able to keep track of their location and status in a more accesible and intuitive way.

My Role

My primary role in this project was database management. I implemented database functionality that supports login, signup, and contact which lets users send us messages if they happen to have any question or inquiries.

I also implemented front end pages, specifically the About Us page which shows the users who we are and what we do, our mission, and values.

Technologies Used

  • React
  • Node.js
  • MongoDB
  • VS Code
